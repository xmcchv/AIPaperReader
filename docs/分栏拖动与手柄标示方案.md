# 分栏拖动与手柄标示方案

> 状态：已实施（2026-11-26）；`npm run check` / `smoke` / `test:ask-context` 全过，无头浏览器实测拖动、持久化、窄屏隐藏均正常
> 日期：2026-11-26
> 目标：原文 / AI 精读之间可左右拖动调整分栏；两处分隔栏都加「可拖动」小标示

---

## 1. 现状

- 精读视图 `.workspace` 是 CSS Grid 三列：
  ```
  grid-template-columns: minmax(280px, 1.02fr) minmax(300px, 1fr) minmax(300px, 1.08fr);
  ```
  对应 `原文 / AI 精读 / 交互图解`，栏间只有 `.pane { border-right: 1px solid var(--line) }`，**没有可交互的手柄**。
- 图解收起时 `.workspace.diagram-collapsed` 变两列（`1fr / 1.15fr`）。
- 追问区与精读正文之间有 `.ask-resizer`（9px 高，pointer 事件写 `askDock.style.height`），但视觉上只有 `::before` 一条线，hover/drag 才变强调色，**没有任何提示"可拖动"的标示**。
- 窄屏（≤1080px）是单列 + tabs，拖动无意义。

可复用的现成模式：`ask-resizer` 的 pointerdown/pointermove/pointerup + `setPointerCapture` + `user-select:none` —— 列间拖动照此实现，只把纵轴换成横轴。

---

## 2. 目标

1. 原文与 AI 精读之间的边界可**左右拖动**，实时改变两栏宽度；
2. 该边界有可见的**竖向 grip 标示**，让一眼看出可拖动；
3. 追问区与精读之间的边界也加**横向 grip 标示**；
4. 不影响图解栏收起/展开、不影响窄屏 tabs、不影响 PDF 视图。

---

## 3. 方案总览

| 边界 | 手柄元素 | 方向 | 拖动效果 | 本次新增 |
| --- | --- | --- | --- | --- |
| 原文 ↔ AI 精读 | `.pane-resizer`（新，绝对定位） | 左右 `col-resize` | 改前两列宽度 | 拖动 + 竖向 grip |
| AI 精读 ↔ 追问 | `.ask-resizer`（已有） | 上下 `row-resize` | 改追问区高度（已有） | 仅加横向 grip |

两处共用一套 grip 视觉语言：三个小圆点，静止时弱化色，hover / 拖动时变强调色。

---

## 4. 列间拖动设计

### 4.1 手柄 DOM 与定位

不改 Grid 列数（避免动到 `.pane:last-child`、`diagram-collapsed` 等现有选择器）。在 `#view-paper .workspace` 内加一个绝对定位手柄：

```html
<div id="pane-resizer" class="pane-resizer" role="separator"
     aria-orientation="vertical" title="拖动调整原文与精读的分栏宽度">
  <span class="resizer-grip"></span>
</div>
```

定位在原文栏右边缘（`.workspace` 为 `position: relative`）：

```css
.pane-resizer {
  position: absolute;
  top: 0; bottom: 0;
  left: calc(var(--paper-w, 34%) - 5px);
  width: 10px;
  z-index: 12;
  cursor: col-resize;
  touch-action: none;
}
```

`--paper-w` 是驱动列宽的 CSS 变量（见 4.2），手柄跟着它走，始终压在两栏边界上。

### 4.2 列宽变量

把 Grid 前两列从固定 `fr` 改为变量控制，第三列保持自适应：

```css
.workspace {
  --paper-w: 34%;
  grid-template-columns: var(--paper-w) minmax(300px, 1fr) minmax(300px, 1.08fr);
}
.workspace.diagram-collapsed {
  grid-template-columns: var(--paper-w) minmax(320px, 1fr);
}
```

- 初值 `34%` 接近现在的 `1.02fr : 1fr : 1.08fr`（原文约占 1/3）；
- 用百分比而非 px：`--paper-w` 是 workspace 宽度的百分比，天然随窗口缩放，省去 resize 时重算；
- 第二列用 `minmax(300px, 1fr)` 吸收剩余空间；
- 第三列（图解）保持 `1.08fr`，收起时该列定义消失，逻辑一致。

### 4.3 拖动逻辑（app.js）

照搬 `ask-resizer` 的 pointer 模式，横轴版：

```
pointerdown:
  记录 startX = ev.clientX、startW = 原文栏实际宽度(px)
  setPointerCapture, 加 dragging 类, body.cursor = col-resize
pointermove:
  delta = ev.clientX - startX
  nextPx = clamp(startW + delta, PAPER_MIN, workspaceW - READING_MIN - DIAGRAM_MIN)
  写 workspace.style.setProperty('--paper-w', (nextPx / workspaceW * 100) + '%')
  手柄自动跟随（left: calc(var(--paper-w) - 5px)）
pointerup/cancel:
  清理类与 cursor, 写 localStorage, diagram.fit() + pdfView.fit()
```

约束常量：

- `PAPER_MIN = 280`（与现有 `minmax(280px, …)` 一致）
- `READING_MIN = 300`
- `DIAGRAM_MIN = 300`（图解展开时；收起时为 0）
- 上限公式按图解是否收起取不同 `DIAGRAM_MIN`

拖动结束重排图解与 PDF：列宽变化后 SVG 图解与 PDF 画布尺寸变了，调 `diagram.fit()`；若原文是 PDF 视图且可见，调 `pdfView.fit()`（与现有 `switchPane` 里切回 PDF 的处理一致）。

### 4.4 持久化与响应式

- 比例存 `localStorage['paperlens.paperWidth']`（百分比数值字符串），初始化时读取并写 `--paper-w`，缺省 `34`；
- 存**百分比**而非 px：窗口从大屏拖到小屏时列宽等比缩放，不会出现一栏占满；
- 窄屏（≤1080px）手柄 `display:none`，拖动代码 early-return（用 `matchMedia('(min-width: 1081px)')` 判定）；
- 图解放全屏 zoom（`.pane.zoom` fixed 覆盖）时手柄应被盖住，无需特殊处理。

## 5. 手柄标示（grip）设计

两处统一用一个 3 点 grip，纯 CSS 画（不引图标、不依赖字体字符）：

```css
.resizer-grip {
  width: 3px; height: 3px;
  border-radius: 50%;
  background: var(--muted);
  opacity: 0.6;
  transition: opacity .16s, background .16s;
}
/* 竖向：三点纵排 */
.pane-resizer .resizer-grip {
  box-shadow: 0 6px 0 var(--muted), 0 12px 0 var(--muted);
  margin: -6px 0 0 3px;
}
/* 横向：三点横排 */
.ask-resizer .resizer-grip {
  box-shadow: 6px 0 0 var(--muted), 12px 0 0 var(--muted);
  margin: 3px 0 0 -6px;
}
:hover .resizer-grip, .dragging .resizer-grip {
  background: var(--accent);
  box-shadow-color: var(--accent);  /* 实际写成显式三色，避免不一致 */
  opacity: 1;
}
```

- 竖向 grip 居中于手柄（上下居中用 `top:50%` + `translateY(-50%)` 或 flex）；
- 横向 grip 居中于 ask-resizer（它已有 `position: relative`，加 flex 居中）；
- 静止态弱化、hover/drag 强调，与现有 `.ask-resizer::before` 的变色逻辑一致，可保留那条线作为"轨道"、grip 作为"把手"。

可访问性：手柄加 `role="separator"` + `aria-orientation` + `aria-valuenow`（列宽百分比），`title` 写明"拖动调整…"。

## 6. 追问区手柄标示

`.ask-resizer` 结构改为：

```html
<div class="ask-resizer" id="ask-resizer" role="separator" aria-orientation="horizontal"
     title="拖动调整追问区高度">
  <span class="resizer-grip"></span>
</div>
```

CSS 加 `display:flex; align-items:center; justify-content:center`，放入 grip。拖动 JS **完全不动**（现有 pointer 逻辑已正确）。

## 8. 边界情况

| 情况 | 处理 |
| --- | --- |
| 拖到极限 | clamp 到三栏各自 min，手柄停在边界不再移动 |
| 图解收起态 | 上限用 `DIAGRAM_MIN=0`，可把原文拖到更宽 |
| 窗口 resize | 百分比列宽自动等比缩放，无需 JS 重算 |
| 窄屏 | 手柄隐藏，拖动 early-return，仍是 tabs 单栏 |
| PDF 视图拖动 | 结束后 `pdfView.fit()`，避免页面尺寸错乱 |
| 图解全屏 zoom | z-index 低于 zoom 面板，手柄被自然遮挡 |
| 与图解折叠按钮共存 | 两者独立：折叠改列数、拖动改 `--paper-w`，互不冲突 |
