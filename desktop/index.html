它能做什么

        
    
          
  • 
            对照翻译
            左侧 PDF 分块、右侧逐段中英对照；打一份 PDF 进来就立刻入库，译文只存一份，三处视图共用。
          
    • 
          
  • 
            AI 精读
            原文 / 精读 / 交互图解三栏联动，点哪段看哪段，图解可直接导出。
          
    • 
          
  • 
            知识图谱
            把多篇论文的概念与前置关系织成一张网，节点可回溯到原文出处。
          
    • 
          
  • 
            任意 OpenAI 兼容模型
            DeepSeek / Kimi / OpenAI / 智谱 / Ollama / 自建端点均可；翻译引擎另有十余家可选，免费引擎零配置。

数据与隐私

        

          论文、译文与知识图谱都保存在本机 SQLite（WAL 模式），不上传任何服务器；模型 API Key 只落在本机
          ~/.paperlens/config.json，首次保存时用主密码加密（scrypt + AES-256-GCM），不保存明文。
